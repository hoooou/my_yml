# Clash 节点优选

`聚合配置.yaml` 是原订阅源和分流规则的输入，`节点来源.yaml` 是新增的公开免费来源清单；`优选配置.yaml` 是自动筛选后可直接导入的完整配置，适用于 Clash Meta / Mihomo 客户端。

## 使用

在客户端中添加远程配置：

```
https://raw.githubusercontent.com/hoooou/my_yml/main/%E4%BC%98%E9%80%89%E9%85%8D%E7%BD%AE.yaml
```

将客户端的远程配置刷新间隔设为 24 小时。GitHub 更新文件后，客户端仍需要刷新才能加载新节点。

默认进入“三站稳定”组（没有三站全部通过的节点时使用其他可用分类）。可在“🚀 全局选择”切换“📶 TCP通”“⛔ TCP不通”“🔎 TCP未验证”，然后在对应组里选单个节点，比较云端判定与手机实际体验。全部可被内核解析的节点均保留，方便验证误判；国家/地区分组和非机房分组最多各 30 个。

## 每日更新

GitHub Actions 的“每日节点连通性分类”每天北京时间 **08:00 开始**，支持手动触发。更新结果仍发布到原来的 `优选配置.yaml` 订阅地址；08:00 是计划开始时间，完成后手机刷新订阅即可。

1. 每次拉取原配置的 11 个来源及新增的 6 个公开来源，按连接配置去重。名称不参与去重，不同密码、UUID、协议或传输参数保留。内核无法解析的节点在报告中单独记录。
2. 对全部不同 TCP 主机与端口调用小小 API 的公开 TCPing 接口，每个入口一次，最多 5 次请求/秒。共享入口共用 TCP 结果，不同节点的代理凭据仍分别验证。
3. 明确返回目标匹配且连接成功记为“通”；明确返回“连接失败”记为“不通”；API 限流、超时、异常、目标不匹配、非公网入口和 UDP 协议记为“未验证”。不会把接口失败当作节点连接失败。
4. **只有 TCP 通的节点**，通过该节点检查 Google、YouTube、ChatGPT 网页，各测 **3 轮**，每轮建立新的请求会话。一个网站 3/3 通过才能进入该网站分组，三站都通过才进入“三站稳定”。验证码、403、登录限制或风控记为需人工复核。只读取网页前 16 KB，**完全取消文件下载测速**。
5. 通过节点查询 Cloudflare 实际出口 IP/国家，再查询 IP 类型。无法确认地区时标注“地区未确认”；非机房组只使用明确 `hosting=false` 的节点，并按独立出口 IP 取最多 30 个。排名依据网页通过项数及 TCP 探测延迟，不包含下载速度。
6. 保留所有可解析节点及三个 TCP 分类组，生成配置并通过 Mihomo 校验后提交 `优选配置.yaml`、`连通性报告.json`、`连通性报告.md`。保留原始分流规则和手机订阅地址。

探测服务：

| 服务 | 当前用途 |
|---|---|
| [小小 API](https://xxapi.cn/doc/tcping) | 公开 TCPing 接口，全量自动分类；运营商未公开，结果不能称为移动线路实测 |
| [ITDOG](https://www.itdog.cn/batch_tcping/) | 网页批量对照；安全验证及缺少已验证的公开自动接口时，记录服务不可自动使用，不绕过验证 |
| [TCPING.CN](https://www.tcping.cn/tcping) | 网页多线路对照；自动接口要求人机验证时跳过，其批量页面目前返回空节点列表 |

每轮检查另外两家的服务状态并写入报告，但**不宣称三家都已完成全量检测**。当前自动判定来自小小 API；TCP 通只说明该服务探测点连接到了端口，不保证中国移动、本地客户端、代理认证或实际服务可用。“不通”也仅代表已测探测点失败，可在手机对照是否存在不同线路结果。UDP 无法由 TCP 测试判断，保留在未验证组供手机试用。

网页复测在 GitHub 云端进行。YouTube 网页通过不等于视频能播放；ChatGPT 网页通过不等于可以登录和对话。本地验证请反馈完整节点编号、云端 TCP 分类、本地能否连通、Google 打开、YouTube 播放、ChatGPT 实际对话情况。

`测速报告.*`、`移动小测报告.*` 是历史下载测速/20节点小测结果。新流程以 `连通性报告.*` 为准。所有来源失效或最终配置不能校验时保留旧订阅。

原订阅的 a1 已从固定历史提交地址改为 Gist 最新版本地址；a7 改为 GitHub 原始配置地址。新来源的节点仍需通过本仓库的连通性与网站复测，来源自带的速度或地区标签不作为入选依据。

每次报告列出各来源的下载数量、新增唯一节点、重复数、跳过数、下载状态和内容指纹；每个入选节点记录全部匹配来源。新增唯一数按清单顺序计算，不是来源有效率或速度排名。

编辑 `节点来源.yaml` 的 `sources` 列表可添加来源，`id` 必须唯一，`url` 应是固定的 HTTPS YAML 地址；设 `enabled: false` 可停用。只读取来源节点，不导入外部配置的规则、分组、脚本或本地设置。长期失效、停止更新或只能提供日期文件的候选本次没有接入。

## 修改检测方式

工作流只安装 Mihomo，不安装或调用 clash-speedtest。入口及网页逻辑位于 `scripts/availability.py`；保留原下载测速脚本仅用于历史复现，当前所有工作流均不调用它。网页请求使用独立节点监听端口，不打开 TUN、不修改系统代理。

每地区最多 30 个以及非机房独立出口最多 30 个只限制额外优选分组，不影响三个 TCP 分类组保留全部样本。API 无法提供结果时保留未验证状态。定时触发可能延迟；GitHub 长时间无活动可能暂停定时任务。
